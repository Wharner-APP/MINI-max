# Подключение платёжной системы

Сейчас любая попытка оплаты (Premium, звёзды, подарки, бизнес) показывает: «Не удалось получить API платёжной системы. Пожалуйста, попробуйте позже».

Как подключить позже (`client/src/core/payments.h`):
1. **Через сервер (проще всего):** реализуйте `POST /api/payments/create` (см. `docs/api.md`) — сервер создаёт счёт у платёжного провайдера и возвращает `checkout_url`.
   В `configs/client.toml` поставьте `[payments] provider = "server"`. Клиент откроет страницу оплаты в браузере.
2. **Свой провайдер в клиенте:** наследуйте `IPaymentProvider` и передайте экземпляр в `PaymentManager::instance().setProvider(...)`.

Цены, пакеты звёзд и подарки берутся из `configs/catalog.json` (если файла нет — встроенный `client/src/res/catalog.json`).
